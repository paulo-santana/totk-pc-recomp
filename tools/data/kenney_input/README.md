# Kenney Input Prompts (PlayStation Series font)

`kenney_input_playstation_series.otf` is from Kenney's Input Prompts 1.5 (https://kenney.nl/assets/input-prompts), CC0
(`License.txt`), the same file Longshot ships in third_party/kenney_input. tools/button_icons.py draws the DualSense
controller picture (glyph controller_playstation5) over the game's Pro Controller illustration for `--prompts playstation`.
